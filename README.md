# 자나깨나 | JANAKKENA — 공개 웹사이트

나주의 역사와 문화유산을 디지털 명품 쇼룸 형태로 재창작한 웹사이트입니다. 제공된 **8개 제품 이미지**와 **자나깨나 골드 로고**가 적용되어 있습니다.

## 구성

- `public/index.html` : 공개 쇼룸 메인 페이지
- `public/assets/` : 브랜드 로고, 8개 제품 최적화 이미지, 스타일과 기능 코드
- `public/catalog.json` : 최초 기본 컬렉션 (가격 미정 = 가격 문의)
- `netlify/functions/` : 관리자 로그인, 제품/영상 저장, 사진 업로드, 생성형 AI 해설
- `netlify.toml` : Netlify 공개 배포 설정

## 1. 로컬 미리보기

`public/index.html`을 브라우저로 직접 열어 볼 수 있습니다. 또는 로컬 웹 서버를 실행할 수 있습니다:

```sh
cd janakkena_website/public
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열어 감상합니다. 로컬 미리보기에서는 비밀번호 **7777**로 관리자를 열어볼 수 있고, 입력 내용은 해당 브라우저의 `localStorage`에만 저장됩니다. **로컬 상태는 다른 방문자에게 공유되지 않습니다.**

## 2. 인터넷 공개 배포 — Netlify

**GitHub 저장소에 `janakkena_website` 폴더 안의 내용을 올린 다음** Netlify에서 `Add new project → Import an existing project`를 선택하고 GitHub 저장소를 연결합니다. `netlify.toml`을 자동 인식하도록 repository root는 웹사이트 폴더여야 합니다. Netlify에서 빌드를 진행하면 자동으로 `*.netlify.app` 공개 주소가 발급됩니다.

**Netlify 사이트 설정의 Environment variables에 다음 값을 등록한 다음 재배포해야 관리자 모드가 작동합니다:**

| Key | Value | 설명 |
|---|---|---|
| `ADMIN_PIN` | `7777` | 요청하신 초기 관리자 비밀번호. 공개 운영 시 **즉시 더 긴 비밀번호로 변경 권장** |
| `SESSION_SECRET` | 32자 이상의 임의의 비밀 문자열 | 관리자 쿠키 서명용. 절대 웹페이지 코드에 공개하지 않음 |
| `OPENAI_API_KEY` | 본인 OpenAI API 키 | **선택 사항.** 설정하면 실제 생성형 AI 해설 가능. 별도의 사용 요금이 발생할 수 있음 |
| `OPENAI_MODEL` | `gpt-5.4-mini` | 선택 사항. 계정에서 쓸 수 있는 모델에 맞게 변경 가능 |

자세한 환경 변수 설정: https://docs.netlify.com/build/functions/environment-variables/

### 로그인

공개 웹사이트 오른쪽 위의 메뉴 아이콘 → 비밀번호 입력 → 로그인. 관리자 모드에서 제품 가격, 이름, 설명, 문화유산 이야기, 이미지(파일 업로드), 신제품 추가/삭제, YouTube 영상 URL, 메인 문구를 편집할 수 있습니다. 변경한 자료는 Netlify Blobs에 저장되어 **모든 방문자에게 동일하게** 보입니다.

### 유튜브 URL

일반 YouTube URL (`https://www.youtube.com/watch?v=...`), `https://youtu.be/...`, Shorts 링크를 지원합니다. 외부 공유 금지 영상은 재생할 수 없습니다.

### AI 해설

실제 AI는 **서버 측 OpenAI API 호출**이며 API 키가 브라우저에 노출되지 않습니다. 모델 호출이 불가능한 경우에는 사전에 등록된 큐레이터 해설을 대신 표시합니다. 각 제품의 기본 AI 설명이 생성되면 키-값 저장소에 보관하여 추가 호출을 줄이며, IP별 사용량을 제한합니다.

### 주의 사항

- `7777`은 4자리라 매우 취약합니다. 로그인 시도 제한을 구현했어도 **실제 운영에서는 긴 비밀번호를 사용하세요.** 관리자 비밀번호는 HTML에 노출하지 않고 서버 환경 변수로 보관합니다.
- 브랜드 이미지에 들어 있는 'TV / TOY VUITTON' 모노그램 및 장식은 제3자 브랜드의 상표·트레이드드레스와 유사하게 보일 수 있습니다. **상업적 사용/공개 전 지식재산권 검토 및 독자적인 문양으로 재디자인**하는 것을 권장합니다. 사이트에는 제휴·판매 아님을 고지했습니다.
- 이미지들은 AI 제작 콘셉트이며 실제 상품 재고나 판매 능력을 입증하지 않습니다. 제품 기본 가격은 임의로 정하지 않아 '가격 문의'로 표시됩니다.
- Netlify 계정, 도메인, API 키는 포함되지 않습니다. 이 파일만으로 인터넷에서 공개된 상태는 아니며 배포 단계가 필요합니다.
- 사이트 공개 및 개인정보 처리, 실제 쇼핑몰 결제·재고·배송 기능은 별도 구축 범위입니다.
